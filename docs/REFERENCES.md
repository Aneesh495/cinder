# Technical references

These references establish external contracts only. They are not imported implementations.

- [WG14 projects and defect history](https://www.open-std.org/jtc1/sc22/wg14/www/projects.html): language issue tracking and published editions.
- [C11 committee draft N1570](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf): baseline syntax and semantic terminology; Cinder documents deliberate profile choices.
- [WG14 issue records](https://www.open-std.org/jtc1/sc22/wg14/issues/): defect-resolution checks.
- [System V x86-64 ABI project](https://gitlab.com/x86-psABIs/x86-64-ABI): calling convention and data classification.
- [ELF generic ABI](https://gabi.xinuos.com/elf/00-header.html): object format relationships.
- [ELF relocation reference](https://refspecs.linuxfoundation.org/elf/gabi4%2B/ch4.reloc.html): relocation semantics.
- [LLVM libFuzzer documentation](https://llvm.org/docs/LibFuzzer.html): comparative fuzzing workflow, not a Cinder dependency.
- [LLVM undefined behavior background](https://llvm.org/docs/UndefinedBehavior.html): comparative optimizer discussion, not Cinder's language definition.

Tool versions and evidence hashes belong in acceptance artifacts rather than being implied by this document.
